What is Archicad? Archicad builds a three-dimensional model of a building that can be inspected, rendered, and checked before construction.  
Why use it for 3d architecture? Working in 3D exposes spatial conflicts that flat drawings hide, and the same model feeds presentation images.  
Who needs it? Architects, visualisation artists, and design teams presenting concepts to clients and planners.  
Does it support photorealistic rendering? Yes, Archicad includes a rendering engine with materials, lighting, and camera settings for client presentations.

## Troubleshooting Common Issues

Install issues? Update the GPU driver before the first launch, since older drivers crash the 3D view.  
Performance problems? Reduce render resolution, close background apps, and render overnight for final images.  
License/activation? Re-enter the subscription account if the licence check fails at launch.  
Compatibility? Convert legacy library parts when older projects fail to display correctly.  
Update failures? Install the latest point release when the render engine reports missing components.
